## Movie Explorer (React + TMDb)

This React app integrates with themoviedb.org (TMDb) to display up-to-date movie data, including trending and popular titles, and provides full-text search across the entire catalog.

---

### Home: Trending and Popular Movies

![Home page showing a grid of popular movies with posters, ratings, and release dates](https://github.com/user-attachments/assets/3e9ea2d6-7918-4ac2-b626-be87769bec00)
Displays the most popular movies right now with live data from TMDb, including poster art, user ratings, and release dates.

### Search: Find Any Movie in TMDb

![Search results listing matched movies with posters and key metadata](https://github.com/user-attachments/assets/f0d26cfd-9340-4c0f-806f-376cd04cc9ee)
Type a title to search the full TMDb database and quickly jump into a specific movie’s details.
